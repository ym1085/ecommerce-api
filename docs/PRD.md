# PRD: farm-market-platform

## 목표

중소 규모 B2C 쇼핑몰 백엔드 REST API를 제공한다. 회원이 상품을 탐색하고 장바구니에 담아 주문·결제까지 완료할 수 있는 핵심 구매 흐름을 지원한다.

## 사용자

일반 소비자 (구매자)

## 핵심 기능

1. **회원** — 회원가입, 로그인, 내 정보 조회, 배송지 등록·조회·수정·삭제
2. **상품** — 상품 목록 조회 (페이징), 상품 상세 조회
3. **장바구니** — 상품 추가, 장바구니 조회, 수량 수정, 항목 삭제
4. **주문** — 주문 생성, 주문 목록 조회 (페이징), 주문 상세 조회
5. **배송** — 배송 상태 조회
6. **결제** — 결제 처리, 결제 상태 조회

## 현재 범위 외 (추후 검토)

- 리뷰·평점 기능
- 상품 검색 (전문 검색 엔진 연동)
- 관리자 기능 (상품 등록·재고 관리·주문 관리)
- 쿠폰·할인·포인트
- 알림 (이메일·SMS·푸시)
- 소셜 로그인 (OAuth2)

## 비고

- 프론트엔드(frontend 모듈)는 현재 미구현. 백엔드 REST API만 제공.
- 인증·인가 전략(JWT 등)은 별도 ADR로 결정 예정.
